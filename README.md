# locality

Make a filesystem understandable through its conceptual address, functional neighborhood, boundaries, and navigable paths.

## Use

> Show me where this subsystem lives, what surrounds it, and how its placement affects its role.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `locality/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
